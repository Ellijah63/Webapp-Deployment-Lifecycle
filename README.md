# Webapp-Deployment-Lifecycle

Jenkins | AWS(EC2) | Tomcat | Maven | GitHub

Jenkins - Develop a pipeline that redirects the deployment to a desired environment using parameters (Dev, QA, Prod)
GitHub - Jenkinsfile will be stored here and checkout to Jenkins when build starts
AWS - using desired EC2 instance depending on environment requirement
Tomcat - Web server tool for java applications
Maven - Auto builder for java applications
